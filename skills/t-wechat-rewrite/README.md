# 转述型公众号写作技能

一个通用的转述型公众号长文写作助手，支持任何人使用并自定义个人风格。

## 特点

- ✅ **通用化**：不限定个人风格，支持任何人使用
- ✅ **可配置**：首次使用引导配置，后续自动读取
- ✅ **4种结构**：自动根据原文类型选择最合适的文章结构
- ✅ **场景化案例**：根据目标读者自动匹配合适的案例场景
- ✅ **分析确认**：写作前先分析确认方向，避免返工

## 快速开始

### 1. 首次使用

运行技能时会自动进入配置向导，只需回答3个问题：
1. 你的署名是什么？（如"你好，我是张三"）
2. 你的目标读者是谁？（如"育儿父母"）
3. 你的写作风格？（口语化/专业/幽默/自定义）

配置完成后，会自动保存到 `~/.claude/wechat-rewrite/config.md`

### 2. 开始写作

配置完成后，直接发送原文即可：

```
/t-wechat-rewrite

[粘贴你要转述的文章内容]
```

技能会：
1. 分析原文，推荐最合适的文章结构
2. 提炼核心观点和金句候选
3. 等你确认后再写完整文章

### 3. 临时覆盖配置

如果这次写作想临时改变配置：

```
/t-wechat-rewrite --author="临时署名" [原文]
/t-wechat-rewrite --reader="临时读者群" [原文]
/t-wechat-rewrite --style="临时风格" [原文]
```

## 4种文章结构

技能会自动根据原文类型选择：

- **结构A：观点提炼型** - 适合观点密集的内容
- **结构B：故事+洞见型** - 适合有核心故事的内容
- **结构C：我不同意型** - 适合有争议或需要补充的内容
- **结构D：概念讲透型** - 适合深度讲解一个核心概念

## 目标读者场景库

根据配置的目标读者，自动匹配合适的案例场景：

- **育儿父母**：婴儿护理、儿童教育、亲子互动
- **自媒体创作者**：公众号运营、小红书、短视频制作
- **职场人士**：工作效率、团队协作、职业发展
- **技术开发者**：编程实践、工具使用、系统架构
- **通用场景**：学习方法、生活习惯、个人成长

## 修改指令

文章输出后，可以快速修改：

- `金句换一个` - 重新生成金句
- `换结构B` - 用另一种结构重写
- `开头重写` - 只重写开头部分
- `第X个观点展开` - 扩写某个观点
- `整体缩短` - 压缩字数

## 常见问题

**Q: 配置文件在哪里？**
A: `~/.claude/wechat-rewrite/config.md`

**Q: 可以有多个配置吗？**
A: 目前只支持一个配置，但可以用临时覆盖参数（`--author`、`--reader`、`--style`）

**Q: 如何重置配置？**
A: 运行 `/t-wechat-rewrite --setup` 或直接删除配置文件

**Q: 必须配置吗？**
A: 是的，首次使用必须配置，之后会自动读取

## 技能原理

1. **第零步**：检查配置，首次使用引导配置
2. **第一步**：读取配置（署名、读者、风格）
3. **第二步**：接收原文
4. **第三步**：分析原文，推荐结构，输出确认
5. **第四步**：根据确认写作完整文章
6. **第五步**：自查清单，确保质量
