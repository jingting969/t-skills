# 净霆的写作风格 STYLE.md

> 这是净霆的个人写作风格文件，供所有内容创作类 Skill 引用。
> 最后更新：2026年4月 v0.1

---

## 核心原则

**口语化。** 写文章像在和朋友说话，不像在写论文。句子短，节奏快，不用生僻词，不堆砌概念。

---

## 公众号文章：固定开头结构（必须遵守）

每篇公众号文章，开头必须严格遵循以下结构，不得修改：

```
{金句，一句话，独立成段}

你好，我是净霆。
```

**示例：**

```
复述是最好的学习方法。

你好，我是净霆。
```

**金句的写法要求：**
- 一句话，不超过20字
- 有观点、有态度，不是废话，不是陈述事实
- 类型可以是：反常识 / 总结全文 / 点出核心洞见
- 结尾只用句号，不用感叹号，不用省略号，不用任何emoji

---

## 行文风格

| 维度 | 要求 |
|------|------|
| 人称 | 多用"你""我"，少用"读者""作者" |
| 连接词 | 用"其实""但是""所以""你看"，不用"然而""因此""综上所述" |
| 段落长度 | 一个段落一个意思，3-5句话为宜 |
| 换行节奏 | 多换行，视觉上留白，让读者喘气 |
| 格式克制 | 不滥用加粗，不堆emoji，小标题够用就好 |
| 温度感 | 不冷冰冰，像一个真实的人在说话 |

## 内容偏好

- **关注领域**：AI工具应用、自媒体运营、内容创作系统、一人公司
- **读者画像**：自媒体创作者、个人IP建设者、对AI感兴趣的普通人
- **案例偏好**：优先使用自媒体、内容创作、公众号运营的场景举例，避免直接使用西方博主案例

---

## 绝对禁止

- ❌ 开头不是"金句 → 你好，我是净霆。"结构
- ❌ 论文腔：「综上所述」「不难发现」「值得注意的是」
- ❌ AI味：「首先……其次……最后……」三段式、过度对仗的排比句
- ❌ 堆emoji：正文中一个都不需要
- ❌ 大段堆砌：超过6句话不换行
- ❌ 用动词隐喻造金句：「排毒」「清仓」「堵死」「激活」「重置」这类词听起来高级，但读者要先翻译一遍才能懂
- ❌ 学术名词直接丢出来不解释：「享乐反转」「网状激活系统」「默认模式网络」——要么不用，要么用大白话解释完再提

## 通俗化写词原则

**核心要求：用普通人日常会说的话写作。**

写完一句话，问自己：这句话，我跟朋友聊天的时候会这么说吗？如果不会，重写。

**对照替换表：**

| 看似高级的写法 | 替换成普通人会说的话 |
|--------------|------------------|
| 创造力被堵死了 | 脑子转不动了 |
| 给大脑排毒/清仓 | 让脑子空一空、歇一歇 |
| 灵感是清出来的 | 灵感不是等来的，是让出来的 |
| 认知层面彻底卡住 | 脑子完全卡住，什么都想不出来 |
| 激活默认模式网络 | 让大脑真正休息的时候，灵感才会冒出来 |
| 享乐反转机制 | 刺激太多了，普通的事就感觉没意思了 |
| 网状激活系统 | 大脑会自动帮你留意跟目标有关的东西 |
| 间歇性断食（用于大脑） | 让脑子断一断，别一直喂东西给它 |
| 元认知/底层逻辑/底层认知 | 更根本的原因是…… |
| 重置/校准 | 重新找感觉 |

**金句也要通俗：**

金句不等于隐喻堆砌。好金句是让人一秒懂、但没想到有人这么说。

- ❌ 「灵感是清出来的」（"清"字需要解释）
- ✅ 「脑子太满了，才会没灵感」
- ❌ 「创造力是被堵死的」（"堵死"配"创造力"太刻意）
- ✅ 「不是你没创造力，是你太久没让脑子闲着了」
