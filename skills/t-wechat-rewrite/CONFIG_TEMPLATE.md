# 转述型公众号写作配置模板

> 这是配置文件模板，用于参考。
> 实际配置文件会在首次使用时自动生成到 `~/.claude/wechat-rewrite/config.md`

---

## 示例配置1：育儿父母博主

```markdown
---
# 转述型公众号写作配置
# 创建时间：2026-08-08
---

## 基本信息

**署名：** 你好，我是张妈妈。

**目标读者：** 育儿父母

**写作风格：** 口语化、轻松对话（像和朋友聊天）

## 风格细节

**开头结构：**
- 金句（一句话，20字以内，有观点）
- 署名

**行文特点：**
- 口语化，像和朋友说话
- 段落短，3-5句话一段
- 多换行，视觉留白
- 多用"你""我"，少用"读者""作者"

**禁忌事项：**
- 避免论文腔（综上所述、不难发现）
- 避免AI味（首先其次最后的三段式）
- 不滥用加粗和emoji

**案例场景偏好：**
- 婴儿护理、儿童教育场景
- 亲子互动、家庭教育案例
- 真实育儿经历
```

## 配置文件说明

### 必填字段
- **署名**：出现在文章开头的自我介绍
- **目标读者**：决定案例场景的选择
- **写作风格**：决定整体行文调性

### 可选字段
- **风格细节**：可以详细描述，也可以简单几句
- **案例场景偏好**：列出常用的案例场景类型

### 修改配置
配置文件可以随时手动编辑，下次写作时会自动读取最新配置。

### 重新配置
运行 `/wechat-rewrite --setup` 可以重新进行交互式配置。
